# LoadLink — Frontend

React 19 + Vite SPA. See the [root README](../README.md) for the project overview, architecture, and setup.

```bash
npm install
npm run dev      # dev server at http://localhost:5173
npm run build    # type-check + production build
npm test         # Vitest
npm run lint     # ESLint
npm run format   # Prettier
```
